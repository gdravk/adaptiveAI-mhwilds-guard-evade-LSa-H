1. With the weapon sheathed the mod does NOTHING: no button presses, no input locks, no recorded touches continuing (reading/learning is fine).
2. When a value the mod measured diverges from what already-tested mods use (e.g. SS stance duration), use the tested mods' value. Reading the value straight from the game is still preferred when available.

**Why:** user stated both on 2026-11-16.
**How to apply:** check new features against rule 1; when importing knowledge from mods in IA-INFOaprendizadoGolpes, prefer their numbers over our measurements. Related: [[so-comandos-reais]], [[estudo-aprendizado-golpes]].
